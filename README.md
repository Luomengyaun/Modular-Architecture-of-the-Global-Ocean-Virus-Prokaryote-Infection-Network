# Modular-Architecture-of-the-Global-Ocean-Virus-Prokaryote-Infection-Network
Analysis code for OVPIN (Ocean Virus–Prokaryote Infection Network), including recursive BRIM-based multiscale modularity analysis, within- and between-module NODF decomposition, robustness analysis across 1,350 perturbed networks, and circular permutation tests for functional enrichment.
